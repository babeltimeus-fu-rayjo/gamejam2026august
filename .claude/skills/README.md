# PixiJS skills for Claude Code

Official PixiJS v8 skills, vendored from [pixijs/pixijs-skills](https://github.com/pixijs/pixijs-skills) (commit `6aae70d`, MIT licensed — see `LICENSE-pixijs-skills`).

Anyone who clones this repo and uses Claude Code gets these automatically — they trigger on any PixiJS work (Application setup, sprites, graphics, text, filters, ticker, performance, etc.). No setup needed.

To update: re-copy the `skills/` directory from the upstream repo over this folder.
