# Seedream 5.0 prompts — Fee & Elara avatar pose sets

Reference slots for every prompt below:

- **image_1** = the matching Teal pose from `game/public/assets/avatars/teal/` (pose + framing + render style)
- **image_2** = the character concept art (identity: face, hair, costume)

Output target: **864 × 1152 (3:4)**, full body head-to-toe, flat pure black background (the
existing Teal set was generated on black and then background-removed to RGBA — do the same).

Final filenames, one per pose, in `game/public/assets/avatars/fee/` and `.../elara/`:
`idle.png`, `good.png`, `great.png`, `perfect.png`, `hype.png`, `miss.png`, `combobreak.png`.

---

## Shared notes

Teal holds a coffee cup in all seven poses, which is what keeps her silhouette readable
frame-to-frame. Each new character gets a one-handed signature prop in the same hand so the
poses transfer cleanly, with the big weapon carried on the back (occupying the same visual slot
as Teal's shoulder bag):

- **Fee** — holds a single green-fletched arrow; quiver of arrows on her back.
- **Elara** — cups a floating crescent-moon sigil; scythe slung diagonally across her back.
