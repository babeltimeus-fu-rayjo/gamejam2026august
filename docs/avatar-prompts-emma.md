# Seedream 5.0 prompts — Emma avatar pose set

Reference slots for every prompt below:

- **image_1** = the matching Teal pose from `game/public/assets/avatars/teal/` (pose + framing + render style)
- **image_2** = Emma's concept art (identity: face, hair, costume)

Output target: **864 × 1152 (3:4)**, full body head-to-toe, flat pure black background, then
background-removed to RGBA like the existing Teal set.

Files go in `game/public/assets/avatars/emma/` as `idle.png`, `good.png`, `great.png`,
`perfect.png`, `hype.png`, `miss.png`, `combobreak.png`.

Prop note: Teal holds a coffee cup in all seven frames, which is what keeps her silhouette
readable frame-to-frame. Emma's stand-in is a small fan of playing cards, held in the same hand,
matching her croupier-style uniform.
